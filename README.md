# nuxt-tw-template

Шаблон Nuxt 4 + Tailwind CSS v4 с базовой структурой `src/app` / `src/shared`, ESLint, Stylelint и Prettier.

## Требования

- Node.js >= 24.6.0
- Yarn 4.15.0

## Установка

```bash
yarn install
```

## Разработка

```bash
yarn dev
```

## Линтинг

```bash
yarn lint        # проверка
yarn lint:fix    # автоисправление
```

## Сборка

```bash
yarn build
```
